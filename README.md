# 📰 资讯聚合系统 (News Aggregator)

一个现代化的资讯聚合网站前端，支持 RSS 信源采集、智能评分、分类浏览和每日日报生成。

## ✨ 功能特性

- 📋 **资讯列表** — 瀑布流展示，按评分智能排序，精选推荐位
- 🔥 **每日日报** — 自动生成每日精选资讯汇总
- ⚙️ **信源管理** — 支持添加/删除/启停 RSS 信源
- 🔄 **一键采集** — 点击"换一换"刷新全部资讯
- 🏷️ **分类浏览** — 技术、行业、财经、科学、人工智能等多分类
- 📱 **响应式设计** — 完美适配桌面端和移动端
- 🔍 **搜索功能** — 快速找到感兴趣的资讯

## 🚀 快速开始

### 前置条件

- 后端 API 服务运行在 `http://localhost:5001`
- 现代浏览器（Chrome / Firefox / Safari / Edge）

### 运行方式

直接在浏览器中打开 `index.html` 即可：

```bash
# 方式一：直接双击打开
open index.html

# 方式二：使用本地服务器（推荐）
python3 -m http.server 8080
# 然后访问 http://localhost:8080
```

## 🛠️ 技术栈

- **前端**：原生 HTML + CSS + JavaScript（零依赖）
- **样式**：CSS 变量 + Grid 布局 + 响应式设计
- **后端 API**：RESTful API（需单独部署）
- **数据存储**：SQLite / MySQL（后端负责）

## 🎯 API 接口

前端通过以下接口与后端通信：

| 接口 | 方法 | 说明 |
|------|------|------|
| `/api/news` | GET | 获取资讯列表 |
| `/api/daily` | GET | 获取每日日报 |
| `/api/sources` | GET | 获取信源列表 |
| `/api/sources` | POST | 添加信源 |
| `/api/sources/:id` | DELETE | 删除信源 |
| `/api/sources/:id/toggle` | POST | 启停信源 |
| `/api/collect` | POST | 触发采集 |
